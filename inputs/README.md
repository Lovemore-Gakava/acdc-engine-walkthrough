# The inputs

What CDISC's app hands its R engine when Execute is pressed, for the ALT endpoint, saved as
files. Produced by `capture/` from the app at commit `739344c`, the saved chain and study
definition from usdm-acdc-in-practice (tag `quickstart-2026-11.2`), and the step-8 settings in
`capture/step8-settings.json`. Do not edit these to fix a result; edit a copy to experiment.

| File | What it is | Comes from |
| --- | --- | --- |
| `spec.json` | The endpoint and its analysis: the method, the slices (which records), the bindings (which concept plays which role) | Built by the app from the saved chain and the USDM, with the step-8 slice settings applied |
| `overrides.json` | Two variable choices: `Measure -> BASE`, `Treatment -> TRT01P` | Typed at step 8 |
| `derivations.json` | The one derivation, change from baseline (`M.Subtraction`), and its baseline slice | Built by the app from the saved chain |
| `method.json` | The ANCOVA method's definition: roles, configuration and defaults (`alpha = 0.05`) | The app's method library |
| `r_impl.json` | The R code that runs ANCOVA: a template with role placeholders | The app's implementation catalogue |
| `r_impls.json` | R code for every method a derivation might use (19 of them) | The app's implementation catalogue |
| `mapping.json` | Which variable in SDTM, ADaM, OMOP or FHIR is which concept | The app's concept-variable mappings |
| `concept_categories.json` | Groups of concepts that stand for the same dimension | The app's concept categories |
| `unit_conversions.json` | Unit conversion factors (not used by this endpoint) | The app's unit library |
| `bootstrap.R` | The R code the app runs: it parses the files above and calls `acdc_execute()` | Generated by the app |

The study's own decisions are in the first three files. The rest are the app's libraries,
shared by every study. [DECISIONS.md](../DECISIONS.md) picks the decisions out.
